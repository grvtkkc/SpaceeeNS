Our project, is an interactive film, which covers the story of/and through the lens of some lander, rovers, and satellites that were sent by NASA, and are now decommissioned. 

It personifies the lander, rovers, and satellites, so normal people can also feel connected to them as much as the scientists do.

We used html, css, ffmpeg and other resources, we coded in VS Code, with some help from Claude Code (SI) to develop this project.

We make it in an interactive film format, which is a mix of traditional and modern techniques and technology.

We consider the true story, and used our poetry and personification skills, to enhance emotion.
